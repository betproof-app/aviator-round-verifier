Aviator round verifier

Paste the seeds of a finished Aviator round from the game's round history. The page joins them in the order the game uses, hashes them with SHA-512 and computes the multiplier. If it matches what the game showed, the round was not changed after the fact. Everything runs in your browser; nothing is sent anywhere.

The result appears here.

The two formulas

VersionString hashed with SHA-512Multiplier
Spribeserver seed + client seeds 1, 2, 3floor(97 · 252 / (252 − h)) / 100
Aviator Studioclient seeds 1, 2, 3 + server seedfloor(96 · 252 / (252 − h)) / 100

h is the first 13 hexadecimal characters of the hash read as a number. The game never shows less than 1.00x. Both formulas were confirmed by rebuilding real rounds copied from the games; the test file in the repository holds six of them.

What this does not do

It cannot predict a round. The server seed is shown only after the round, and SHA-512 offers no shortcut. The chance that a round reaches a multiplier x is about 0.97 / x in the Spribe version, so every cash-out target returns about 97% of the stake over time.
